# Day 8: Maa Mahagauri Abhishek - Cinematic Visual Storytelling 🌸✨

A cinematic mythological story animation created purely using **Python** and **OpenCV** for Navratri Day 8 (Maa Mahagauri).

Instead of a traditional sketch, this project programmatically animates the sacred legend of Mother Parvati: following severe penance in the Himalayas, her form had darkened, and when Lord Shiva performed Gangajal Abhishek, her divine, radiant, snow-white **Mahagauri** form was revealed.

---

## 🛠️ Tech Stack & Requirements

* **Language:** Python 3.8+
* **Libraries:** OpenCV (`cv2`), NumPy

---

## 🚀 How to Run the Project

### 1. Clone the Repository
```bash
git clone [https://github.com/Gracyclub/Day-8-Mahagauri-Story-Python.git](https://github.com/Gracyclub/Day-8-Mahagauri-Story-Python.git)
```
```
cd Day-8-Mahagauri-Story-Python
```

### 2. Install Required Dependencies
```bash
pip install opencv-python numpy
```

### 3. Verify Asset Filenames
Ensure your three scene images are present in the project folder:
* `mahagauri_scene_1.png` (or `.jpg`)
* `mahagauri_scene_2.png` (or `.jpg`)
* `mahagauri_scene_3.png` (or `.jpg`)

### 4. Run the Animation Script
```bash
python day8.py
```

### 5. Controls
* Press **q** to exit the animation at any time.
* Press any key at the end to close the window.
